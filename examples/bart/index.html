A PyMC model with a pymc_bart.BART term, sampled by PyMC's own CompoundStep under Pyodide: bartrs's particle Gibbs on the trees, NUTS on sigma. Every log density either sampler asks for is compiled with mode="WASM". The first run installs PyMC, which takes tens of seconds.
