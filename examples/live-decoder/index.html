A tiny decoder, trained right here

compiled & fit live via tapewasm's compileTape() + advi() — what's that mean? Nothing on this page was precompiled: compile writes a tape by hand (z → Dense(2→20) → sigmoid → Dense(20→196) → sigmoid) and compiles it to a wasm module, and train fits it — the same wasm runtime the rest of pymcwasm samples with. 32 real MNIST digits (posteriordb's subset), downsampled to 14×14 so training takes seconds, not tens of them. An earlier version fit linear probabilistic PCA instead; its reconstructions matched textbook 2-component PCA almost exactly — the problem, since 2 linear components only explain ~27% of the variance across 8 digit classes. This nonlinear decoder, same 2D latent space, roughly halves that reconstruction error.

Model

zᵢ  ~ N(0, I₂)
hᵢ  = sigmoid(W₁ᵀzᵢ + b₁)
μᵢ  = sigmoid(W₂ᵀhᵢ + b₂)
xᵢⱼ ~ N(μᵢⱼ, 0.15²)

Shaded: observed pixel. Double circle: deterministic. Not a VAE — there is no encoder. Each zᵢ is its own parameter, fit jointly with the weights by mean-field ADVI.
