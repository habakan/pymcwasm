A PyMC model, compiled ahead of time, sampled in this browser

No server sampled this and no Python is running here — the page holds a wasm module built from a PyMC log density and a NUTS sampler, and nothing else. Press sample again and the chain runs from scratch.

Parameters are in the space the sampler works in, so a name ending _log__ is on the log scale. The dashed red line is where nutpie put the mean for the same model.
