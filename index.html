pymcwasm

A PyMC model's log density compiled to WebAssembly and sampled by nuts-rs, in the page. Two ways in.

Write the model here → PyMC runs in the tab under Pyodide. Edit the model, compile it, sample it. Costs a Python runtime on first load — tens of seconds. Seven compiled beforehand → No Python anywhere. Each model is a wasm module of a few tens of kilobytes, checked against nutpie.
